# ⚡ Abhishek Kumar Dutta — Developer Portfolio

> Personal portfolio engineered with vanilla web technologies, featuring a scroll-driven 150-frame canvas engine, custom vector brand identity, and obsidian dark theme aesthetics.

## 🚀 Key Highlights

- **Scroll-Driven Canvas Engine:** 150-frame smooth video canvas sequence with LERP sub-pixel interpolation.
- **Pure Vanilla Stack:** Zero frontend frameworks or heavy runtime bloat (HTML5, Vanilla CSS3, Modern ES6+).
- **Interactive UI & 3D Tilt:** Dynamic specular glare, cursor ambient tracking, and magnetic buttons.
- **Selected Project Showcases:**
  - [LeetMetric](https://abhishek-commits-hub.github.io/LeetMetric/) — Algorithmic progress dashboard.
  - [Nexora](https://abhishek-commits-hub.github.io/Nexora/) — Modern e-commerce platform.
- **Accessibility & Performance:** Native reduced-motion query support (`prefers-reduced-motion`) and Retina DPI canvas scaling.

## 🛠️ Tech Stack

- **Markup:** Semantic HTML5
- **Styling:** Vanilla CSS3 (Custom Design Tokens, CSS Grid & Flexbox)
- **Logic:** Vanilla JavaScript (ES6+, Canvas API, IntersectionObserver)
- **Assets:** Custom Scalable Vector Graphics (SVG)
