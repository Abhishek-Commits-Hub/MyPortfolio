# ⚡ Abhishek Kumar Dutta — Developer Portfolio

Personal developer portfolio engineered with modern vanilla web architecture, featuring a 150-frame interactive canvas animation sequence, obsidian-inspired dark theme, and bespoke vector branding.

🔗 **Live Portfolio:** [abhishek-commits-hub.github.io/MyPortfolio/](https://abhishek-commits-hub.github.io/MyPortfolio/)

---

## 🌟 Key Features

- **150-Frame Cinematic Scroll Canvas:** Smooth video scrub animation with sub-pixel LERP interpolation and high-DPI Retina scaling.
- **Pure Zero-Dependency Stack:** Built entirely with semantic HTML5, modern vanilla CSS3, and ES6+ JavaScript.
- **Interactive Micro-Interactions:** 3D perspective tilt with specular glare, ambient cursor spotlight tracking, and magnetic buttons.
- **Featured Live Projects:**
  - **[LeetMetric](https://abhishek-commits-hub.github.io/LeetMetric/)** — LeetCode analytics and algorithmic progress dashboard.
  - **[Nexora](https://abhishek-commits-hub.github.io/Nexora/)** — High-performance responsive e-commerce platform.
- **Custom Vector Identity:** Scalable SVG cybernetic monogram badge (`logo.svg`) styled to match the obsidian/neon orange palette.

## 🚀 Running Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/Abhishek-Commits-Hub/MyPortfolio.git
   cd MyPortfolio
   ```

2. Start a local server:
   ```bash
   # Using Python
   python -m http.server 8080

   # Or using Node (e.g. npx serve)
   npx serve .
   ```

3. Open `http://localhost:8080` in your browser.
